# Semantic Variation in Hazard Terminology across Safety Standards

Supporting datasets for the paper:

*Semantic Variation in Hazard Terminology across Safety Standards: An Exploratory Analysis of IEC61508*

## Overview

This repository contains annotated contexts from IEC 61508 and ISO/TS 15916 used in an exploratory analysis of semantic variation in hazard-related terminology.

The analysis examines terminology with respect to:
- inferential role
- epistemic goal
- ontological classification

The datasets are intended as analytical research artifacts supporting the discussion of ambiguity, semantic variation, and conceptual alignment in safety standards.

## Files

- `iec61508.csv`
- `iso15916.csv`

## Dataset Structure

Each row represents one analytically relevant context extracted from the standards, typically involving definitions, requirements, notes, or descriptive passages.

The datasets include:
- source references
- contextual text
- extracted hazard-related terminology
- UFO-inspired ontological classifications

Multi-type annotations are intentional and represent contextually plausible alternative interpretations discussed in the paper.

## Acknowledgement

The datasets were produced through iterative manual analysis supported by semi-automated extraction and formatting assistance. Obvious extraction artifacts and malformed tokenization outputs were manually corrected during curation.

## Limitations

The datasets are exploratory rather than normative representations of the standards. Some annotations intentionally preserve ambiguity and semantic variation because these constitute part of the analytical findings of the study.
