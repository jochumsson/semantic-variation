# Semantic Variation

Datasets and supporting material for the paper:

> *Semantic Variation in Hazard Terminology across Safety Standards: An Exploratory Analysis of IEC61508*

The repository contains annotated contexts from IEC61508 and ISO15916 analysed with respect to:
- hazard-related terminology
- inferential role
- epistemic goal
- ontological classification

The work explores how semantic variation contributes to ambiguities and inconsistencies in safety-related knowledge representation.

## Files

- `iec61508.csv`
- `iso15916.csv`
- `methodology.md`

## Note

Only limited contextual excerpts from the standards are included for research and analytical purposes.
